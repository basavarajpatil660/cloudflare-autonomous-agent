# Code of Conduct

## Our standard

This project welcomes contributions from anyone. Participants are expected to be respectful and constructive in issues, pull requests and discussions.

Unacceptable behaviour includes personal attacks, harassment, discriminatory language, and publishing others' private information without permission.

## Scope

This applies in all project spaces — issues, pull requests, discussions and commits — and when representing the project publicly.

## Enforcement

Report concerns to the maintainer via the email on their GitHub profile. Reports will be reviewed and handled confidentially. Maintainers may edit or remove contributions that do not meet this standard, and may block repeat offenders.

This document is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
